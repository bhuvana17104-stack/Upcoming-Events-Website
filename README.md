# Upcoming Events Website

## About the Project
A simple upcoming events website built using HTML. It showcases different events, including a photo gallery event and a fashion store event, along with event information and contact details.

## Features
- Upcoming events section
- Photo gallery event
- Fashion store event
- Event descriptions and information
- Contact details
- Clickable images

## Technologies Used
- HTML5

## Project Structure
- `index.html` – Main website page
- `img/` – Contains website images
